## What shows up in your GitHub stats
- **Contribution graph:** commits to the default branch made with an email address linked to your GitHub account. Private-repository activity appears only if "Include private contributions on my profile" is enabled in your profile settings.
- **Pinned repository:** pin this repository on your profile (Customize your pins). Public repositories only.
- **Stars, forks, followers:** these come from real people finding the work. Share the demo page and a short write-up. Do not buy stars or create artificial commits; that violates GitHub terms.
- **Traffic:** Insights, then Traffic, shows views and clones to you as the owner, for roughly the last 14 days.
- **Releases:** the `v1.1.0` tag and release notes give the repository a visible version history.

## Optional profile README stats card
Create a repository named exactly like your username, then add its README. A pinned-repo card, using a third-party service that you should verify is still available:

```markdown
[![Repo card](https://github-readme-stats.vercel.app/api/pin/?username=Karthick-Udayakumar&repo=ai-agent-engineering-playbook)](https://github.com/Karthick-Udayakumar/ai-agent-engineering-playbook)
```

The public instance of that service can be rate-limited. Self-hosting is the reliable option.
